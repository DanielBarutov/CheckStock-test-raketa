# CheckStock

`make up` собирает и запускает приложение с PostgreSQL. Миграции применяются автоматически, проверка готовности доступна на `http://127.0.0.1:8000/health`. `make down` останавливает контейнеры и сохраняет данные.

Для локальных проверок с Python 3.13 и uv запустите `make test` (pytest с порогом покрытия 95%) или `make check` (тесты, Ruff и mypy).
